1. System Overview & Architecture

1.1 What is Cargo Convoy CRM?

Cargo Convoy CRM is a comprehensive freight brokerage management platform built for Cargo Convoy Inc. It handles the entire lifecycle of freight operations — from customer onboarding and credit management, through load creation and carrier dispatch, to invoicing and payment collection.

Technology Stack: Laravel 12 (PHP 8.4) | MySQL 8 | Blade Templates | Bootstrap 5 | jQuery | Select2 | DataTables | Dompdf | FPDI | PhpSpreadsheet | ApexCharts

6.3 Rate Calculation Formula

How Rates Are Calculated
Customer Side (Revenue)

Base Rate (load_shipper_rate)
+ FSC (Base Rate x FSC%)
+ Other Charges (invoice/non-invoice)
= Customer Final Rate

Carrier Side (Cost)

Carrier Fee (load_carrier_fee)
+ Billing FSC (Fee x FSC%)
+ Other Charges
= Carrier Final Fee

Profit Margin = Customer Final Rate - Carrier Final Fee

7.3 Server-Side Validation (Security)

Atomic Credit Check with Row Locking
Lock Customer Row
→
Check Balance
→
Deduct Amount
→
Save & Release
// CreditService.php — All credit operations use this pattern: DB::transaction(function() { $customer = Customer::whereKey($id)->lockForUpdate()->first(); $available = calculateAvailableCredit($customer); if ($loadAmount > $available) { throw new CreditExceededException("Available: $available, Requested: $loadAmount"); } $customer->remaining_credit = $available - $loadAmount; $customer->remaining_credit_amount = $customer->remaining_credit; $customer->save(); });
Race Condition Protection: The lockForUpdate() prevents two simultaneous requests from reading the same balance. If two brokers create loads at the same time, one will wait for the other to finish — preventing double-spending.
