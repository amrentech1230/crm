1. System Overview & Architecture

1.1 What is Cargo Convoy CRM?

Cargo Convoy CRM is a freight brokerage management system for Cargo Convoy Inc. It manages the full lifecycle of freight loads — from customer setup, load creation, carrier dispatch, through to invoicing and payment collection.

Tech Stack: Laravel 12 (PHP 8.4) | MySQL | Blade Templates | Bootstrap 5 | jQuery | Select2 | Dompdf | FPDI | PhpSpreadsheet

6.2 Load Creation Steps

1
Select Customer (Bill To): Choose an approved customer. Credit limit validated.
2
Set Load Type: OTR or DRAYAGE.
3
Add Shipper(s): Multiple stops supported (up to 15). Location, appointment, commodity.
4
Add Consignee(s): Delivery must be after pickup date.
5
Assign Carrier: Search by Name/MC#/DOT#. Auto-fills details.
6
Set Rates: Customer Rate + FSC + Charges = Final Rate. Carrier fee must not exceed customer rate.
7
Credit Check: Server-side validation blocks if credit exceeded.

6.3 Rate Calculation

Rate Formula
Customer: Base Rate + (FSC% x Rate) + Other Charges = Final Customer Rate
Carrier: Carrier Fee + (FSC% x Fee) + Charges = Final Carrier Fee
Profit: Customer Final Rate - Carrier Final Fee = Margin

6.4 Load Clone

Clone copies all load data but resets rates to 0 and status to "Open". Saves time for repeat shipments.

7.3 Credit Validation (Server-Side)

// CreditService.php - Atomic check + deduction with row locking DB::transaction(function() { $customer = Customer::lockForUpdate()->find($id); $available = calculateAvailableCredit($customer); if ($loadAmount > $available) { return error("Insufficient credit. Available: $available"); } $customer->remaining_credit -= $loadAmount; $customer->save(); });
Security: Credit is validated server-side with database row locking. Users cannot bypass by disabling JavaScript or submitting forms directly.
