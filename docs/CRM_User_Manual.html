1. System Overview & Architecture

1.1 What is Cargo Convoy CRM?

Cargo Convoy CRM is a comprehensive freight brokerage management system designed for Cargo Convoy Inc. It manages the complete lifecycle of freight loads from creation to payment, including customer relationships, carrier management, invoicing, compliance checks, and document handling.

Technology Stack: Laravel 11 (PHP 8.4) | MySQL Database | Blade Templates | Bootstrap 5 | jQuery | Dompdf for PDF generation | PhpSpreadsheet for Excel exports

3.2 Key Security Features

1
Single Session Enforcement: Only one active session per user. If user is already logged in from another device, login is blocked (unless session expired > 1 minute).
2
Active Status Check: Only users with status = "active" can login. Inactive accounts are blocked.
3
Session Management: Old sessions are cleared on new login. LogoutOtherDevices is enforced.
4
Activity Logging: Every login/logout is recorded with username, IP, and timestamp.

6.2 Load Creation Process

1
Select Customer (Bill To): Choose an approved customer. System validates credit limit before allowing creation.
2
Set Load Type: OTR (Over The Road) or DRAYAGE. Type determines rate field editability.
3
Add Shipper(s): Multiple shippers supported. Select from saved shippers or enter new. Includes location, appointment date/time, commodity details.
4
Add Consignee(s): Multiple consignees with delivery appointments. Delivery date must be after pickup date.
5
Assign Carrier: Search by name, MC#, or DOT#. Auto-fills carrier details. System validates carrier exists in database.
6
Set Rates: Customer rate + FSC + other charges = Final Rate. Carrier fee must not exceed customer final rate.
7
Credit Validation: System checks if new load amount would exceed customer's assigned credit limit.

6.3 Credit Limit Validation

// Credit limit check during load creation $assignedCreditLimit = $customer->adv_customer_credit_limit; $totalLoadCreationAmount = Load::where('customer_id', $customerId) ->where('load_status', '!=', 'Cancelled') ->sum('shipper_load_final_rate'); $newTotal = $totalLoadCreationAmount + $loadAmount; if ($newTotal > $assignedCreditLimit) { return error("Cannot create load. Available credit exceeded."); }

6.5 Load Clone Feature

Brokers can clone an existing load to quickly create similar shipments. The clone copies all shipper/consignee info, customer, carrier, and other details but resets rates to 0 and status to "Open".

6.6 Rate Calculation Logic

Rate Calculation Formula
Customer Side:
Customer Rate + (FSC% x Customer Rate) + Other Charges = Shipper Final Rate

Carrier Side:
Carrier Fee + (Billing FSC% x Carrier Fee) + Other Charges = Final Carrier Fee

Profit Margin: Shipper Final Rate - Final Carrier Fee = Margin
